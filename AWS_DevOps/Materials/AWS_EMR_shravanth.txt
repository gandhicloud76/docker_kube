So How AWS EMR works?

	*EMR distributes computation of your data over multiple amazon Ec2 instances
	*Load your data and process into Amazon S3 and then launch Amazon EMR cluster in Minutes and cluster starts processing my data.
	*EMR monitors our job when the job is done it shutdowns the cluster so we stop paying
	*we can easily expand or shrink our EMR cluster to get answers quickly
	*If we store our data in amazon S3 it can accessed bu multiple EMR clusters.
	*Users can increase cluster on Demand or even terminate at any time
		->Lowers cost
		->Reduces Time
	*cluster can be optimized for each application

Process would be like
	1)Store Input data
	2)Run a process on Input data across bunch of computer instances
	3)Store the results

How it is configured?
	1)Master Instance : Assigns the job flow
	2)Core Instance   : Compute Capacity needs for the job
	3)Task Instance   : Extra compute capacity for task that dont require data persistence
	4)Bucket 	  : Stores the results
	5)Another Bucket  : To store the output

Amazon EMR Pricing

	Amazon EMR pricing is simple and predictable: you pay a per-second rate for every second you use, with a one-minute minimum. 
For example, a 10-node cluster running for 10 hours costs the same as a 100-node cluster running for 1 hour. 
The hourly rate depends on the instance type used (e.g. standard, high cpu, high memory, high storage, etc), and billing is calculated down to the 
second and shows time in decimal form. 
Hourly prices range from $0.011/hour to $0.27/hour ($94/year to $2367/year).
