
Data Warehousing:
- Storage area for processed & integrated data across different sources.
- It allows its users to extract required data, for business analysis & strategic decision making.
- Formally the Dataware housing is a STANDALONE Repository of information, Integrated from several, possibily Heterogenous Operational DB.


Evolution of Data Warehousing:
- Before 1970's : It was ppl based and no automated system
- In 1970 : A minimal of data were copied to tape & loaded to files.
- 
End of 1980's : Introduction of RDBMS
- Late 1990's : Small set of datas were copied to a location and thus dataware housing born.


Features of Data Warehousing:
- It is a PROCESS, not a Product.
- It is a process of creating well defined Information management system solution which enables information & analytical processing without the barriers of Geography & Organization.


Creation A Data Warehouse:
Steps involved,
1. Defining a clear ARCHITECTURE.
2. Plan for the Data Warehouse STORAGE capacity
3. Then INTEGRATE the servers/storage/client.
4. Design the SCHEMA & VIEWS
5. Create a Physical Organization & access methods.
6. Define METADATA & Populate its repositories.
7. Connect the SOURCES, Gateways & ODBC Drivers.
8. Design the SCRIPTS for Extract, Load & Refresh.
9. Design & Implement the ENDUSER Applications.

AWS RedShift:

- Amazon Redshift is a fast, fully managed data warehouse that makes it simple and cost-effective to analyze all your data using standard SQL and your existing Business Intelligence (BI) tools. 

Benefits:
- Fast & Inexpensive.
- Secure & Compatible
- It allows you to run complex analytic queries against petabytes of structured data.
- Sophisticated query optimization
- Columnar storage on high-performance local disks
- Parallel query execution.


Features:
- Optimized for Data Warehousing
- Petabyte Scale
- Query your Amazon S3 “data lake”
- Fast Restores
- Encryption [AES-256 encryption]

Pricing in RedShift:

With Amazon Redshift, you can start small for just $0.25 per hour with no commitments and scale out to petabytes of data for $1,000 per terabyte per year, less than a tenth the cost of traditional solutions. Below are the options available,

- On-Demand pricing: no upfront costs - you simply pay an hourly rate based on the type and number of nodes in your cluster.
- Amazon Redshift Spectrum pricing: enables you to run SQL queries directly against all of your data, out to exabytes, in Amazon S3 - you simply pay for the number of bytes scanned.
- Reserved Instance pricing: enables you to save up to 75% over On-Demand rates by committing to using Redshift for a 1 or 3 year term.
